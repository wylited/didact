#+TITLE: RISC-V in an Afternoon
#+SUBTITLE: RV32I assembly on a machine you can single-step, one instruction at a time

* The machine you are about to drive

A RISC-V RV32 processor has 32 registers, =x0= through =x31=, and almost no
surprises. /RISC/ stands for *Reduced Instruction Set Computer*: every
instruction is exactly four bytes, reads at most two registers, and writes at
most one. That is the whole trick — a machine small enough to hold in your
head.

Register =x0= is hard-wired to zero: writes to it are simply discarded. It
sounds useless until you notice it hands you constants, comparisons, and
"move" for free. The registers also have /ABI names/ — the calling
conventions real programs use:

| Register      | ABI name  | Convention                |
|---------------+-----------+---------------------------|
| x0            | zero      | always 0                  |
| x1            | ra        | return address            |
| x2            | sp        | stack pointer             |
| x10–x17       | a0–a7     | arguments, ecall services |
| x5–x7, x28–31 | t0–t6     | temporaries               |
| x8–x9, x18–27 | s0–s11    | saved across calls        |

The right-hand pane is the *machine panel*: all 32 registers plus the =pc=,
the disassembly with the current instruction highlighted, a hex view of
=.data=, and an output console. Since RISC-V has no flags register, the
panel shows a *branch context* line instead: the operands and outcome of the
most recent branch.

* Programs talk with ecall

There is no operating system here, just a small syscall convention in the
spirit of venus and RARS: put a /service number/ in =a7=, any argument in
=a0=, then execute the =ecall= instruction.

| =a7= | Service      | Effect                              |
|------+--------------+-------------------------------------|
| 1    | print int    | write =a0= as a signed decimal      |
| 4    | print string | write NUL-terminated bytes at =a0=  |
| 11   | print char   | write the low byte of =a0=          |
| 10   | exit         | stop the program                    |
| 93   | exit         | same as 10 (Linux convention)       |

* Block 1: hello, ecall

The classic first program. =la= /loads the address/ of a label into a
register and =li= /loads an immediate=; between them we point =a0= at the
string and =a7= at service 4. The block is a live editor — change the text
between the quotes and run it again.

#+NAME: hello
#+BEGIN_SRC asm-riscv
        .text
hello:
        la      a0, msg        # a0 -> address of the string
        li      a7, 4          # service 4: print string
        ecall
        li      a7, 11         # service 11: print char
        li      a0, 10         # '\n'
        ecall
        li      a7, 10         # service 10: exit
        ecall

        .data
msg:
        .asciz "Hello, RISC-V!"
#+END_SRC

#+RESULTS:
: Hello, RISC-V!

* Block 2: a loop that adds 1..10

A loop needs three things: an /induction variable/, a /limit/, and a
backwards branch. Here =t0= counts from 1, =t2= accumulates the sum, and
=blt t1, t0, done= leaves the loop once the counter passes the limit. Press
*Step* repeatedly and watch the accent color follow the registers around the
loop; watch the branch context line flip from /not taken/ to /taken/.

For intuition, here is the same loop in C — non-executable, since only
=asm-riscv= blocks run on this page:

#+BEGIN_SRC c
int sum = 0;
for (int i = 1; i <= 10; i++)
    sum += i;      /* 55 */
#+END_SRC

#+NAME: sum-loop
#+BEGIN_SRC asm-riscv
        .text
        li      t0, 1          # i = 1
        li      t1, 10         # limit = 10
        li      t2, 0          # sum = 0
loop:
        add     t2, t2, t0     # sum += i
        addi    t0, t0, 1      # i++
        blt     t1, t0, done   # if 10 < i, leave the loop
        j       loop
done:
        mv      a0, t2         # a0 = 55
        li      a7, 1          # service 1: print int
        ecall
        li      a0, 10         # newline, as in block 1
        li      a7, 11
        ecall
        li      a7, 10         # exit
        ecall
#+END_SRC

#+RESULTS:
: 55

* Where to go next

- Print =t0= with service 1 /inside/ the loop body to see every partial sum.
- Replace =blt= with =bge= and swap the operands — same exit, different
  comparison to reason about.
- Store the sum to memory with =sw= and read it back with =lw=; find it in
  the .data hex viewer.
- Break something on purpose: type =addd t2, t2, t0= and enjoy a line-mapped
  error instead of a silent wrong answer.
