#+TITLE: JavaScript, Stepped Live
#+SUBTITLE: Type coercion, var vs let closures, hoisting/TDZ, and the event loop on a steppable JS interpreter

This page runs a hand-written JavaScript interpreter instead of your browser's opaque engine so you can single-step every statement, drop gutter breakpoints, and watch *Scopes*, *Call stack*, *Event loop*, and *console* update live.

* Abstract equality (~==~) vs strict equality (~===~)

~===~ checks type and value without conversion. ~==~ coerces operands step by step until their types match, which is how ~[] == false~ evaluates to =true=: =[]= coerces to =''=, =''= coerces to =0=, and =false= coerces to =0=.

| Expression          | Coercion steps                      | Result |
|---------------------+-------------------------------------+--------|
| ~'' == 0~           | =''= -> =0=                         | true   |
| ~'1' == 1~          | ='1'= -> =1=                        | true   |
| ~[] == false~       | =[]= -> =''= -> =0=, =false= -> =0= | true   |
| ~null == undefined~ | spec special case                   | true   |
| ~NaN == NaN~        | =NaN= never equals itself           | false  |
| ~[] === false~      | different types, no coercion        | false  |

#+NAME: coercion
#+BEGIN_SRC javascript
console.log('' == 0, '1' == 1);
console.log([] == false, [] == 0, [7] == 7);
console.log(null == undefined, null == 0, undefined == 0);
console.log(NaN == NaN, NaN === NaN);
console.log([] === false, '1' === 1);
#+END_SRC

#+RESULTS:
: true true
: true true true
: true false false
: false false
: false false

*Try editing:* add ~console.log([] == ![]);~ and run it — =![]= is =false= (arrays are truthy), reducing the check to ~[] == false~.

* Closures capture bindings, not snapshots

A closure holds a reference to the environment slot where a variable lives, not a copy of its value. A ~for (var i = ...)~ loop allocates *one* shared =i= slot for the entire enclosing scope, whereas ~for (let j = ...)~ allocates a fresh =j= slot on every iteration.

* Hoisting and the temporal dead zone

Before line 1 runs, the interpreter registers every declaration in the scope. =var= starts out =undefined= and =function= declarations are immediately callable. =let= and =const= are registered too, but stay in the *temporal dead zone* until their declaration executes — reading =later= on line 5 throws before line 6 runs.

#+NAME: hoisting-tdz
#+BEGIN_SRC javascript
console.log(hoistedVar, typeof hoistedFn);
var hoistedVar = 'now set';
function hoistedFn() { return 'callable before its line'; }
console.log(hoistedVar, hoistedFn());
console.log(later);
let later = 'never reached';
#+END_SRC

#+RESULTS:
: undefined function
: now set callable before its line

*Try editing:* step once from line 1 and look at *Scopes* — =hoistedVar= is already listed as =undefined= before line 2 executes. Now move ~let later = 'now safe';~ above line 5 and re-run to eliminate the TDZ error.

* Event loop order: sync -> microtasks -> macrotasks

Synchronous top-level code runs to completion first. Next, the engine drains the *entire* microtask queue (=Promise.resolve().then(...)=) before taking a single macrotask (=setTimeout(..., 0)=).

#+CAPTION: Event loop priority: synchronous stack, then full microtask drain, then next macrotask
#+BEGIN_SRC typst :results svg

* Exercise: filter evens, double, and join

Fix the =filter= callback so it keeps only even numbers, doubles them, and prints =4 · 8 · 12=. Drop a breakpoint inside the callback to watch *Call stack* push a frame per element.

#+NAME: ex-filter-map
#+EXERCISE: Keep even numbers, double them, and print 4 · 8 · 12
#+CHECK: 4 · 8 · 12
#+BEGIN_SRC javascript
var numbers = [1, 2, 3, 4, 5, 6];
var evens = numbers.filter(function (n) { return n % 2 !== 0; });
var doubled = evens.map(function (n) { return n * 2; });
console.log(doubled.join(' · '));
#+END_SRC

#+BEGIN_HINT
Change ~n % 2 !== 0~ to ~n % 2 === 0~.
#+END_HINT

#+BEGIN_SOLUTION
#+BEGIN_SRC javascript
var numbers = [1, 2, 3, 4, 5, 6];
var evens = numbers.filter(function (n) { return n % 2 === 0; });
var doubled = evens.map(function (n) { return n * 2; });
console.log(doubled.join(' · '));
#+END_SRC
#+END_SOLUTION
