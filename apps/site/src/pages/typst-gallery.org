#+TITLE: Typst Diagram Gallery
#+SUBTITLE: Every figure on this page is one build-time Typst block, compiled to inline SVG

This page is the review surface for the build-time diagram layer: one block per
supported pattern, each caption naming the mechanism it exercises. Nothing here
runs in the browser — the build compiles each block once, the quality gate in
=apps/site/typst/check.ts= inspects the SVG, and the page receives the vector
result. If a block stops compiling, =pnpm build= fails with the page and line.

Open =apps/site/src/pages/typst-gallery.org= next to this page. Every figure is
the source directly above it.
