* Registers and Linux syscalls

On Linux x86-64, =rax= holds the syscall number before =syscall= and the return value afterward. =rdi=, =rsi=, and =rdx= carry the first three arguments, and =rsp= points to the top of a 1 MiB stack.

| Syscall | =rax= | Arguments                      |
|---------+-------+--------------------------------|
| =write= | 1     | =rdi= fd, =rsi= buf, =rdx= len |
| =exit=  | 60    | =rdi= exit code                |

* Writing to stdout

=section .data= places =msg= at =0x601000=, and =msg_len equ $ - msg= computes the byte length at assembly time. Step up to =syscall= and watch =rax=, =rsi=, and =rdx= get loaded; one step past =syscall=, =rip= moves 2 bytes forward and =rax= becomes =14= (the byte count returned by =write=).

#+NAME: hello
#+BEGIN_SRC asm
; hello.asm — your first syscall
; Linux x86-64: syscall number in rax, args in rdi, rsi, rdx.

section .text
start:
    mov rax, 1            ; sys_write
    mov rdi, 1            ; fd 1 = stdout
    mov rsi, msg          ; rsi <- address of the string
    mov rdx, msg_len      ; rdx <- how many bytes to write
    syscall               ; write(1, msg, 14) -> rax = 14

    mov rax, 60           ; sys_exit
    xor rdi, rdi          ; exit code 0
    syscall               ; the machine stops here

section .data
msg:     db "Hello, world!", 10    ; 10 = '\n'
msg_len  equ $ - msg
#+END_SRC

#+RESULTS:
: Hello, world!

* Loops, flags, and turning numbers into ASCII

To print =55= without libc, you divide by =10= and add ='0'= (=0x30=) to each digit. Here =rax= sums =1..10= while =rbx= counts up; watch =ZF= and =CF= update on =cmp rbx, 10= before =jbe next= branches. Then =div rcx= splits =rdx:rax= into quotient (=rax = 5=) and remainder (=rdx = 5=) and writes both ASCII digits into =digits=.

#+NAME: sum-loop
#+BEGIN_SRC asm
; sum.asm — sum 1..10 and print the result
; 1 + 2 + ... + 10 = 55, which is exactly two ASCII digits.

section .text
start:
    xor rax, rax          ; sum = 0
    mov rbx, 1            ; i = 1
next:
    add rax, rbx          ; sum += i
    inc rbx               ; i++
    cmp rbx, 10           ; flags: i vs 10
    jbe next              ; loop while i <= 10 (short backward jump)

    ; split 55 into digits: 55 / 10 = 5 remainder 5
    mov rcx, 10
    xor rdx, rdx          ; rdx must be 0 before div (rdx:rax / rcx)
    div rcx               ; rax = 5 (tens), rdx = 5 (ones)
    add al, '0'           ; 5 -> ASCII '5'
    add dl, '0'
    mov [digits], al      ; store tens digit into the buffer
    mov [digits+1], dl    ; store ones digit
    mov byte [digits+2], 10   ; newline

    mov rax, 1            ; write(1, digits, 3)
    mov rdi, 1
    mov rsi, digits
    mov rdx, 3
    syscall

    mov rax, 60           ; exit(0)
    xor rdi, rdi
    syscall

section .data
digits:  db "00", 10      ; scratch buffer, overwritten at run time
#+END_SRC

#+RESULTS:
: 55

After running, look at *Memory · .data* at =0x601000=: =30 30 0a= (="00\n"=) turned into =35 35 0a= (="55\n"=). Hit Reset to watch it revert.

* Syntax reference

- Intel syntax, destination first (=mov rax, 42=)
- Labels (=name:=) and NASM-style =.local= labels
- Sections: =section .text= / =section .data= (or =.text= / =.data=)
- Data: =db=, =dw=, =dd=, =dq= with numbers, chars, and strings
- Constants & math: =name equ expr= (or =name = expr=), =+ - * /=, =0x=, =0b=, ='a'=
- Memory operands: =[digits+1]=, =byte [digits+2]=, =[rax]=, =[rsp+8]=
- Comments start with =;=
