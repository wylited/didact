#+SUBTITLE: The i32 core of WAT: operand stack, locals, structured control flow, and linear memory

* Arithmetic on an operand stack

WebAssembly has no registers. Instructions push values onto an operand stack and pop them back off: =i32.const= pushes a 32-bit integer, and =i32.add= pops two and pushes their sum. The nested syntax =(i32.add (i32.const 20) (i32.const 22))= flattens to pushing =20=, pushing =22=, then running =i32.add=.

Step through the block below and watch *Instructions* (which shows the real binary opcodes: =0x41= for =i32.const=, =0x6a= for =i32.add=) alongside *Operand stack*. Overflow wraps modulo =2^32= (=65536 * 65536 = 0=), and signed division =i32.div_s= truncates toward zero (=-7 / 2 = -3=).

#+NAME: stack-arith
#+BEGIN_SRC wasm
(module
  (import "didact" "print" (func $print (param i32)))
  (func (export "main")
    (call $print (i32.add (i32.const 20) (i32.const 22)))
    (call $print (i32.mul (i32.const 65536) (i32.const 65536)))
    (call $print (i32.div_s (i32.const -7) (i32.const 2)))))
#+END_SRC

#+RESULTS:
: 42
: 0
: -3

* Locals and recursive calls

Function parameters and =(local ...)= declarations give you named per-call variables (zero-initialized). =local.get= pushes a local onto the stack and =local.set= pops the top value into it. Each =call= pushes a fresh frame onto the *Call stack* panel; step into =$fact= below to watch ten frames stack up and then unwind as each multiply finishes.

#+NAME: factorial
#+BEGIN_SRC wasm
(module
  (import "didact" "print" (func $print (param i32)))
  (func $fact (param $n i32) (result i32)
    (if (result i32) (i32.le_s (local.get $n) (i32.const 1))
      (then (i32.const 1))
      (else (i32.mul (local.get $n) (call $fact (i32.sub (local.get $n) (i32.const 1)))))))
  (func (export "main")
    (call $print (call $fact (i32.const 10)))))
#+END_SRC

#+RESULTS:
: 3628800

* =block=, =loop=, and =br=

WebAssembly has no arbitrary jumps. Control flow is built from nested =block= and =loop= labels, and =br= means opposite things depending on which one you name: =br $done= (a =block=) jumps to the end like =break=, while =br $again= (a =loop=) jumps back to the top like =continue=. =br_if= branches only when the top of the stack is nonzero.

#+NAME: counted-loop
#+BEGIN_SRC wasm
(module
  (import "didact" "print" (func $print (param i32)))
  (func (export "main")
    (local $i i32)
    (local $sum i32)
    (block $done
      (loop $again
        (br_if $done (i32.gt_s (local.get $i) (i32.const 5)))
        (local.set $sum (i32.add (local.get $sum) (local.get $i)))
        (local.set $i (i32.add (local.get $i) (i32.const 1)))
        (br $again)))
    (call $print (local.get $sum))))
#+END_SRC

#+RESULTS:
: 15

* Linear memory is just bytes

=(memory 1)= allocates one 64 KiB page of flat byte-addressed memory. =i32.store8= writes the low byte, =i32.load8_u= reads it back unsigned (=0..255=), and =i32.load8_s= sign-extends it. Four-byte loads and stores are little-endian. Here =0x2A= (42, ASCII =*=) is stored at address =0= and printed once as a char and once as an integer. Check the *Memory* panel to see byte =2a= at =0x0000=.

#+NAME: memory-bytes
#+BEGIN_SRC wasm
(module
  (import "didact" "print" (func $print (param i32)))
  (import "didact" "print_char" (func $print_char (param i32)))
  (memory 1)
  (func (export "main")
    (i32.store8 (i32.const 0) (i32.const 0x2A))
    (call $print_char (i32.load8_u (i32.const 0)))
    (call $print (i32.load8_u (i32.const 0)))))
#+END_SRC

#+RESULTS:
: *42

This kernel implements the =i32= core (stack, locals, globals, calls, structured branches, linear memory, and traps for divide-by-zero, =unreachable=, and out-of-bounds memory). =i64=, =f32=, and =f64= fail cleanly at load time. The opcode bytes in *Instructions* are the real binary spec encodings emitted by clang in the C and C++ lessons.
