#+TITLE: WebAssembly: The Stack Machine Underneath
#+SUBTITLE: Single-step through the i32 core of WebAssembly (WAT) — stack ops, locals, structured control flow, and linear memory

* No registers — just an operand stack

WebAssembly is a *stack machine*. Instead of naming registers, instructions push values onto an operand stack and pop them back off: =i32.const= pushes a 32-bit integer, and =i32.add= pops two and pushes their sum.

The nested S-expression syntax =(i32.add (i32.const 20) (i32.const 22))= is just syntactic sugar for pushing =20=, pushing =22=, then running =i32.add=. Step through the block below and watch the *Instructions* panel (which shows the real binary opcodes: =0x41= for =i32.const=, =0x6a= for =i32.add=) alongside the *Operand stack* panel.

Two =i32= arithmetic rules to notice:

- Overflow wraps silently modulo =2^32= (=65536 * 65536 = 0=).
- Signed division =i32.div_s= truncates toward zero (=-7 / 2 = -3=).

#+NAME: stack-arith
#+BEGIN_SRC wasm
(module
  (import "didact" "print" (func $print (param i32)))
  (func (export "main")
    (call $print (i32.add (i32.const 20) (i32.const 22)))
    (call $print (i32.mul (i32.const 65536) (i32.const 65536)))
    (call $print (i32.div_s (i32.const -7) (i32.const 2)))))
#+END_SRC

#+RESULTS:
: 42
: 0
: -3

* Locals and recursive calls

Values that need to live across expressions go in *locals* (parameters first, then =(local ...)= declarations, all zero-initialized). =local.get= pushes a local onto the stack; =local.set= pops the top of the stack into it.

Every =call= creates a fresh call frame with its own locals and operand stack slice. Step into =$fact= below and watch the *Call stack* panel grow one frame per recursive call, then unwind as each frame returns its product.

#+NAME: factorial
#+BEGIN_SRC wasm
(module
  (import "didact" "print" (func $print (param i32)))
  (func $fact (param $n i32) (result i32)
    (if (result i32) (i32.le_s (local.get $n) (i32.const 1))
      (then (i32.const 1))
      (else (i32.mul (local.get $n) (call $fact (i32.sub (local.get $n) (i32.const 1)))))))
  (func (export "main")
    (call $print (call $fact (i32.const 10)))))
#+END_SRC

#+RESULTS:
: 3628800

* Structured control flow: =block=, =loop=, and =br=

WebAssembly has no arbitrary =goto=. Instead, control flow uses nested =block= and =loop= labels, and =br= behaves differently depending on which one you target:

- =br $done= (targeting a =block=) jumps to the *end* of the block — like =break=.
- =br $again= (targeting a =loop=) jumps to the *start* of the loop — like =continue=.
- =br_if= branches only when the top of the stack is nonzero.

Putting a =loop= inside a =block= gives you a standard counted loop: =br_if $done= exits when =$i > 5=, and =br $again= repeats otherwise.

#+NAME: counted-loop
#+BEGIN_SRC wasm
(module
  (import "didact" "print" (func $print (param i32)))
  (func (export "main")
    (local $i i32)
    (local $sum i32)
    (block $done
      (loop $again
        (br_if $done (i32.gt_s (local.get $i) (i32.const 5)))
        (local.set $sum (i32.add (local.get $sum) (local.get $i)))
        (local.set $i (i32.add (local.get $i) (i32.const 1)))
        (br $again)))
    (call $print (local.get $sum))))
#+END_SRC

#+RESULTS:
: 15

* Linear memory: just a flat byte array

=(memory 1)= allocates one 64 KiB page of flat, byte-addressed memory. =i32.store8= writes the low byte of a value; =i32.load8_u= reads it back unsigned (=0..255=), while =i32.load8_s= sign-extends it. Four-byte =i32.store=/=i32.load= are little-endian.

Below, we store =0x2A= (42, ASCII =*=) at address =0= and read it back twice — once as a character and once as an integer. Check the *Memory* panel to see byte =2a= appear at offset =0x0000=.

#+NAME: memory-bytes
#+BEGIN_SRC wasm
(module
  (import "didact" "print" (func $print (param i32)))
  (import "didact" "print_char" (func $print_char (param i32)))
  (memory 1)
  (func (export "main")
    (i32.store8 (i32.const 0) (i32.const 0x2A))
    (call $print_char (i32.load8_u (i32.const 0)))
    (call $print (i32.load8_u (i32.const 0)))))
#+END_SRC

#+RESULTS:
: *42

* Scope of this kernel

This interpreter implements WebAssembly's *32-bit integer core*: operand stack, locals, globals, function calls, structured branches, linear memory, wrapping =i32= math, and real traps (divide by zero, =unreachable=, out-of-bounds memory access — all mapped to your source line). Types outside that core (=i64=, =f32=, =f64=) are rejected cleanly at load time.

The opcode bytes shown in the *Instructions* panel are real WebAssembly binary encodings — the exact same instruction format clang emits in the C and C++ lessons.
