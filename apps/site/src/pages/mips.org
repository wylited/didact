#+TITLE: MIPS32 Assembly, Step by Step
#+SUBTITLE: SPIM/MARS-style MIPS32 assembler and fetch-decode-execute simulator in your browser

Every block on this page is assembled into real 32-bit MIPS32 machine words and run by a steppable fetch-decode-execute interpreter in TypeScript. The *Program* listing shows the exact encoded bytes at each address.

One standard teaching simplification (matching SPIM and MARS defaults): *there are no branch delay slots*. Branches take effect immediately, and =jal=/=jalr= store =pc + 4= into =$ra=.

* Registers, =hi=/=lo=, and no flags

MIPS32 has 32 general-purpose registers with standard ABI roles:

| Registers                  | Role                                                         |
|----------------------------+--------------------------------------------------------------|
| =$zero=                    | hardwired 0 (writes are ignored)                             |
| =$at=                      | assembler temporary (reserved for pseudo-instructions)       |
| =$v0=, =$v1=               | return values; =$v0= also picks the syscall                  |
| =$a0=–=$a3=                | first four function/syscall arguments                        |
| =$t0=–=$t9=                | caller-saved scratch registers                               |
| =$s0=–=$s7=                | callee-saved registers                                       |
| =$gp=, =$sp=, =$fp=, =$ra= | global pointer, stack pointer, frame pointer, return address |

Two quirks distinguish MIPS from x86:

- *Separate =hi= and =lo= registers:* =mult= writes a 64-bit product across =hi:lo=, and =div= puts the quotient in =lo= and remainder in =hi=. Use =mflo= and =mfhi= to copy those values back into normal registers.
- *No condition flags:* Instead of setting ZF/CF flags, comparisons write =0= or =1= into a register (=slt=), and branches test registers directly (=beq=, =bne=, =blez=, etc.). Pseudo-instructions like =ble $t1, 10, loop= expand into real instructions (=addiu= + =slt= + =beq=) that you can see in the listing.

* Syscalls

Put the service number in =$v0=, put the argument in =$a0=, and run =syscall=:

| =$v0= | Service      | Argument in =$a0=                  |
|-------+--------------+------------------------------------|
| 1     | print int    | signed 32-bit integer              |
| 4     | print string | address of a NUL-terminated string |
| 11    | print char   | ASCII code                         |
| 10    | exit         | none (halts execution)             |

Memory is little-endian (=.text= at =0x00400000=, =.data= at =0x10010000=, =$sp= at =0x7fffeffc=), and runs are capped at 1,000,000 instructions so infinite loops stop cleanly.

* Hello, MIPS

Step through this program and notice that =la $a0, msg= expands into *two* machine instructions (=lui= + =ori=), because the 32-bit address =0x10010000= does not fit in a 16-bit immediate. Hover any listing row to read the source comment.

#+NAME: hello
#+BEGIN_SRC mips
# hello-mips.asm — your first two syscalls
        .data
msg:    .asciiz "Hello, MIPS!\n"      # NUL-terminated string in .data
        .text
main:   li      $v0, 4                  # syscall 4: print string at $a0
        la      $a0, msg                # la = load address (a pseudo-op)
        syscall
        li      $v0, 10                 # syscall 10: exit
        syscall
#+END_SRC

#+RESULTS:
:Hello, MIPS!

* Counting loop: sum 1..10

This loop accumulates =1..10= in =$t0= using =$t1= as the counter. It uses =addu= and =addiu= (the non-trapping unsigned forms) because MIPS's signed =add=/=addi= trap on signed overflow.

#+NAME: sum
#+BEGIN_SRC mips
# sum-1-to-10.asm — accumulate 1..10 in $t0, print it
        .text
main:   li      $t0, 0                  # sum = 0
        li      $t1, 1                  # i = 1
loop:   addu    $t0, $t0, $t1           # sum += i
        addiu   $t1, $t1, 1             # i++
        ble     $t1, 10, loop           # while (i <= 10) loop
        move    $a0, $t0                # print sum (55)
        li      $v0, 1                  # syscall 1: print int in $a0
        syscall
        li      $a0, 10                 # 10 = '\n'
        li      $v0, 11                 # syscall 11: print char in $a0
        syscall
        li      $v0, 10                 # exit
        syscall
#+END_SRC

#+RESULTS:
:55

* Function calls and =mult=/=mflo=: =factorial(10)=

=jal fact= jumps to =fact= and saves the return address in =$ra=; =jr $ra= returns. Inside the loop, =mult= writes the 64-bit product to =hi:lo= and =mflo= pulls out the low 32 bits. For =10!=, =lo= reaches =3628800= while =hi= stays =0= (try bumping =10= to =13= to see =hi= become nonzero).

#+NAME: factorial
#+BEGIN_SRC mips
# fact-10.asm — factorial(10) = 3628800 via mult / mflo
        .text
main:   li      $a0, 10                 # n = 10
        jal     fact                    # call fact; $ra <- return address
        move    $a0, $v0                # print the result
        li      $v0, 1
        syscall
        li      $a0, 10                 # '\n'
        li      $v0, 11
        syscall
        li      $v0, 10
        syscall

fact:   li      $v0, 1                  # result = 1
        li      $t0, 2                  # i = 2
loop:   mult    $v0, $t0                # hi:lo = result * i (a full 64 bits)
        mflo    $v0                     # result <- low 32 bits
        addiu   $t0, $t0, 1             # i++
        ble     $t0, $a0, loop          # while (i <= n)
        jr      $ra                     # return: pc <- $ra
#+END_SRC

#+RESULTS:
:3628800

* Supported syntax quick reference

- SPIM/MARS syntax, destination first: =add $t0, $t1, $t2=, with =#= comments
- Registers by ABI name (=$t0=) or number (=$8=); =$fp= and =$s8= are aliases
- Sections and data: =.data=, =.text=, =.word=, =.half=, =.byte=, =.asciiz=, =.ascii=, =.space=, =.align=
- Addressing: =offset($reg)=, =($reg)=, =label=, =label+4=, absolute constants
- Pseudo-ops: =li=, =la=, =move=, =nop=, =not=, =neg=, =mul=, =rem=, 3-operand =div=, =beqz=, =bnez=, =b=, =blt=, =bgt=, =ble=, =bge=
- Core ISA: =add/addu/sub/subu/addi/addiu=, =and/or/xor/nor= (+ immediate forms), =sll/srl/sra= (+ variable forms), =slt/sltu/slti/sltiu=, =mult/multu/div/divu=, =mfhi/mflo/mthi/mtlo=, =lb/lbu/lh/lhu/lw/sb/sh/sw=, =beq/bne/blez/bgtz/bltz/bgez=, =j/jal/jr/jalr=, =syscall=

Assembly and runtime errors (bad registers, signed overflow on =add=, divide by zero, unaligned =lw=, or writing to =.text=) always report the exact source line.
