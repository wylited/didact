* Pseudo-instructions expand into real words

MIPS assembly lets you write convenient pseudo-instructions like =la= (load 32-bit address) and =ble= (branch if less than or equal), even though a 32-bit instruction word can only carry a 16-bit immediate. The assembler quietly rewrites them using the reserved assembler temporary =$at= before execution starts.

* Unsigned arithmetic vs signed overflow traps

Compilers emit =addu= and =addiu= for ordinary integer math because MIPS =add= and =addi= raise a hardware arithmetic-overflow trap when a signed 32-bit sum crosses $2^(31) - 1 = 2147483647$.

#+NAME: sum
#+BEGIN_SRC mips
# sum-1-to-10.asm — accumulate 1..10 in $t0
        .text
main:   li      $t0, 0                  # sum = 0
        li      $t1, 1                  # i = 1
loop:   addu    $t0, $t0, $t1           # sum += i (wraps instead of trapping)
        addiu   $t1, $t1, 1             # i++
        ble     $t1, 10, loop           # expands to slt + beq using $at
        move    $a0, $t0                # print 55
        li      $v0, 1
        syscall
        li      $a0, 10                 # '\n'
        li      $v0, 11
        syscall
        li      $v0, 10                 # exit
        syscall
#+END_SRC

#+RESULTS:
: 55

*Try editing:* set a breakpoint on =ble $t1, 10, loop= and step through its expanded instructions to see =$at= change in *Registers*. To see a real MIPS overflow trap, replace =li $t0, 0= with =li $t0, 2147483647= and change =addu= to =add=.

* 64-bit products in =hi:lo= and =jal=/=jr= calls

Multiplying two 32-bit integers can produce up to 64 bits. Rather than writing two general registers at once, =mult= stores the full 64-bit product across dedicated =hi= and =lo= registers; you pull the halves back with =mflo= and =mfhi=.

#+CAPTION: 64-bit mult result split across hi (bits 63..32) and lo (bits 31..0)
#+BEGIN_SRC typst :results svg
#set text(size: 9pt)
#set page(margin: 12pt)
#import "@preview/cetz:0.5.2": canvas, draw

#context {
  let mono(body, size: 9pt, fill: black) = text(font: "DejaVu Sans Mono", size: size, fill: fill, body)
  let half-w = calc.max(
    measure(mono[hi (bits 63..32)]).width,
    measure(mono[lo (bits 31..0)]).width,
    measure(mono(size: 8pt)[mfhi -> high 32]).width,
    measure(mono(size: 8pt)[mflo -> low 32]).width,
    ) + 42pt
  let op-w = measure(mono[\$v0 (32-bit)]).width + 20pt

  canvas({
  import draw: *
  let accent = rgb("#1A9988")
  let warm = rgb("#B3402E")
  let cx = half-w
  let right = 2 * half-w
  let y-bot = 0pt
  let y-mid = 26pt
  let y-arrow = y-mid + 46pt
  let y-op = y-mid + 40pt
  let y-op-top = y-op + 26pt
  let mid = (y-bot + y-mid) / 2

  // 64-bit product split into hi / lo halves
  rect((0pt, y-bot), (cx, y-mid), stroke: 1pt + warm, fill: rgb("#FDF3F1"))
  rect((cx, y-bot), (right, y-mid), stroke: 1pt + accent, fill: rgb("#F2F8F6"))
  content((cx / 2, mid), mono[hi (bits 63..32)])
  content((cx + cx / 2, mid), mono[lo (bits 31..0)])

  // operands
  rect((cx / 2 - op-w / 2, y-op), (cx / 2 + op-w / 2, y-op-top), stroke: 0.8pt + luma(120), fill: white)
  rect((cx + cx / 2 - op-w / 2, y-op), (cx + cx / 2 + op-w / 2, y-op-top), stroke: 0.8pt + luma(120), fill: white)
  content((cx / 2, (y-op + y-op-top) / 2), mono[\$v0 (32-bit)])
  content((cx + cx / 2, (y-op + y-op-top) / 2), mono[\$t0 (32-bit)])
  content((cx, (y-op + y-op-top) / 2), text(size: 11pt)[×])

  // mult writes the full 64-bit product into hi:lo
  line((cx, y-arrow), (cx, y-mid), stroke: 1pt + accent, mark: (end: ">", fill: accent))
  content((cx + 9pt, (y-mid + y-arrow) / 2), anchor: "west", mono(size: 8.5pt, fill: accent)[mult \$v0, \$t0])

  // reads back out
  content((cx / 2, y-bot - 15pt), mono(size: 8pt, fill: warm)[mfhi -> high 32])
  content((cx + cx / 2, y-bot - 15pt), mono(size: 8pt, fill: accent)[mflo -> low 32])
  })
}
#+END_SRC

Step into =jal fact= below and watch =$ra= capture the return address (=pc + 4=) while *hi · lo · pc* updates on every =mult=.

#+NAME: factorial
#+BEGIN_SRC mips
# fact-10.asm — factorial(10) = 3628800 via mult / mflo
        .text
main:   li      $a0, 10                 # n = 10
        jal     fact                    # $ra <- return address; pc <- fact
        move    $a0, $v0
        li      $v0, 1
        syscall
        li      $a0, 10                 # '\n'
        li      $v0, 11
        syscall
        li      $v0, 10
        syscall

fact:   li      $v0, 1                  # result = 1
        li      $t0, 2                  # i = 2
loop:   mult    $v0, $t0                # hi:lo = result * i (64 bits)
        mflo    $v0                     # result <- low 32 bits
        addiu   $t0, $t0, 1             # i++
        ble     $t0, $a0, loop          # while (i <= n)
        jr      $ra                     # return: pc <- $ra
#+END_SRC

#+RESULTS:
: 3628800

*Try editing:* change =li $a0, 10= to =li $a0, 13= and re-run. Because $13! = 6227020800 > 2^(32) - 1$, *hi · lo · pc* shows ~hi = 1~ — the overflowed upper 32 bits that =mflo= silently discarded! Compare this with [[file:c.org][32-bit overflow in C]].
