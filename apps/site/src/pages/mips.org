#+TITLE: MIPS32 Assembly, Stepped Live
#+SUBTITLE: SPIM/MARS-style MIPS32 assembler and fetch-decode-execute simulator in your browser

Every block here assembles to real 32-bit MIPS32 words and runs on a steppable fetch-decode-execute interpreter. Check the *Program* listing to see the actual encoded bytes at each PC address. Like SPIM and MARS in default mode, there are no branch delay slots: branches jump immediately, and =jal=/=jalr= save =pc + 4= into =$ra=.

* Registers, =hi=/=lo=, and no flags

| Registers                  | Role                                                         |
|----------------------------+--------------------------------------------------------------|
| =$zero=                    | hardwired 0 (writes are ignored)                             |
| =$at=                      | assembler temporary (reserved for pseudo-instructions)       |
| =$v0=, =$v1=               | return values; =$v0= also selects the syscall                |
| =$a0=–=$a3=                | first four arguments                                         |
| =$t0=–=$t9=                | caller-saved scratch                                         |
| =$s0=–=$s7=                | callee-saved                                                 |
| =$gp=, =$sp=, =$fp=, =$ra= | global pointer, stack pointer, frame pointer, return address |

Two things feel different if you come from x86. First, =mult= writes a 64-bit product across two special registers (=hi:lo=), and =div= puts the quotient in =lo= and remainder in =hi=; you pull them back with =mflo= and =mfhi=. Second, MIPS has no condition flags: comparisons write =0= or =1= into a register (=slt=), and branches compare registers directly. Pseudo-instructions like =ble $t1, 10, loop= expand into real machine instructions (=addiu=, =slt=, =beq=) that you can watch in the listing.

* Syscalls

Load the service number into =$v0=, put the argument in =$a0=, and execute =syscall=:

| =$v0= | Service      | Argument in =$a0=                  |
|-------+--------------+------------------------------------|
| 1     | print int    | signed 32-bit integer              |
| 4     | print string | address of a NUL-terminated string |
| 11    | print char   | ASCII code                         |
| 10    | exit         | none                               |

Memory is little-endian (=.text= at =0x00400000=, =.data= at =0x10010000=, =$sp= at =0x7fffeffc=), with a 1,000,000-instruction run cap.

* Hello, MIPS

Step through this block and watch =la $a0, msg= expand into two instructions (=lui= + =ori=), since the 32-bit address =0x10010000= does not fit in a 16-bit immediate. Hover any row in the listing to see its =#= comment.

#+NAME: hello
#+BEGIN_SRC mips
# hello-mips.asm — your first two syscalls
        .data
msg:    .asciiz "Hello, MIPS!\n"      # NUL-terminated string in .data
        .text
main:   li      $v0, 4                  # syscall 4: print string at $a0
        la      $a0, msg                # la = load address (a pseudo-op)
        syscall
        li      $v0, 10                 # syscall 10: exit
        syscall
#+END_SRC

#+RESULTS:
:Hello, MIPS!

* Summing 1 through 10

This loop adds =1..10= into =$t0= using =addu= and =addiu=. Compilers prefer the =u= forms because signed =add=/=addi= trap on signed overflow.

#+NAME: sum
#+BEGIN_SRC mips
# sum-1-to-10.asm — accumulate 1..10 in $t0, print it
        .text
main:   li      $t0, 0                  # sum = 0
        li      $t1, 1                  # i = 1
loop:   addu    $t0, $t0, $t1           # sum += i
        addiu   $t1, $t1, 1             # i++
        ble     $t1, 10, loop           # while (i <= 10) loop
        move    $a0, $t0                # print sum (55)
        li      $v0, 1                  # syscall 1: print int in $a0
        syscall
        li      $a0, 10                 # 10 = '\n'
        li      $v0, 11                 # syscall 11: print char in $a0
        syscall
        li      $v0, 10                 # exit
        syscall
#+END_SRC

#+RESULTS:
:55

* Calls and =mult=/=mflo=: =factorial(10)=

=jal fact= saves the return address in =$ra= and jumps; =jr $ra= jumps back. Each =mult= writes a 64-bit product to =hi:lo= and =mflo= reads the low 32 bits. For =10!=, =lo= ends at =3628800= and =hi= stays =0=. Bump =10= to =13= to see =hi= go nonzero.

#+NAME: factorial
#+BEGIN_SRC mips
# fact-10.asm — factorial(10) = 3628800 via mult / mflo
        .text
main:   li      $a0, 10                 # n = 10
        jal     fact                    # call fact; $ra <- return address
        move    $a0, $v0                # print the result
        li      $v0, 1
        syscall
        li      $a0, 10                 # '\n'
        li      $v0, 11
        syscall
        li      $v0, 10
        syscall

fact:   li      $v0, 1                  # result = 1
        li      $t0, 2                  # i = 2
loop:   mult    $v0, $t0                # hi:lo = result * i (a full 64 bits)
        mflo    $v0                     # result <- low 32 bits
        addiu   $t0, $t0, 1             # i++
        ble     $t0, $a0, loop          # while (i <= n)
        jr      $ra                     # return: pc <- $ra
#+END_SRC

#+RESULTS:
:3628800

* Syntax reference

- SPIM/MARS syntax, destination first (=add $t0, $t1, $t2=), =#= comments
- Registers by ABI name (=$t0=) or number (=$8=); =$fp= and =$s8= are the same register
- Sections and data: =.data=, =.text=, =.word=, =.half=, =.byte=, =.asciiz=, =.ascii=, =.space=, =.align=
- Memory operands: =offset($reg)=, =($reg)=, =label=, =label+4=, constants
- Pseudo-ops: =li=, =la=, =move=, =nop=, =not=, =neg=, =mul=, =rem=, 3-operand =div=, =beqz=, =bnez=, =b=, =blt=, =bgt=, =ble=, =bge=
- Core ISA: =add/addu/sub/subu/addi/addiu=, =and/or/xor/nor= (+ =i=), =sll/srl/sra= (+ =v=), =slt/sltu/slti/sltiu=, =mult/multu/div/divu=, =mfhi/mflo/mthi/mtlo=, =lb/lbu/lh/lhu/lw/sb/sh/sw=, =beq/bne/blez/bgtz/bltz/bgez=, =j/jal/jr/jalr=, =syscall=

Assembly and runtime errors (bad registers, overflow on =add=, divide by zero, unaligned =lw=, stores to =.text=) report the exact source line.
