#+TITLE: RISC-V (RV32IM), Stepped Live
#+SUBTITLE: Fixed-width 32-bit instructions, register-direct branches, and byte sign-extension

This page runs a pure-TypeScript RV32IM interpreter: 32 integer registers (=x0=–=x31=), the =M= multiply/divide extension, and fixed 4-byte instructions. Click *Step* or set a gutter breakpoint on any instruction to inspect *Registers*, *Branch* (which records the operands and outcome of the most recent comparison), *Disassembly*, *.data*, and *Output*.

* Register roles and flagless branches

Two design choices separate RISC-V from [[file:x86-64-assembly.org][x86-64]]:

- =x0= (=zero=) is permanently wired to =0=. Every write to =x0= is discarded, which eliminates dedicated =nop= and =mov= encodings.
- There is no flags register. Branch instructions like =blt t1, t0, done= compare two registers and decide whether to jump in one step.

#+CAPTION: RV32IM register-direct branch versus x86-style flags
#+BEGIN_SRC typst :results svg
#set page(margin: 12pt)

#context {
  let mono = "DejaVu Sans Mono"
  let teal = rgb("#1A9988")

  ).width / 1pt
  let th(body, size: 9pt, font: "DejaVu Sans", weight: "regular") = measure(
    text(body, size: size, font: font, weight: weight),
  ).height / 1pt

  let lh1 = th("t1 = 10", font: mono, weight: "bold")
  let lh2 = th("rs1 (limit)", size: 8pt)
  let lead = 5
  let texth = lh1 + lh2 + lead
  let boxh = texth + 14
  let pad = 9
  let vgap = 10
  let gap = 26
  let hw = 64
  let hh = 30

  let wl = calc.max(
      tw("t1 = 10", font: mono, weight: "bold"),
      tw("rs1 (limit)", size: 8pt),
      tw("t0 = i", font: mono, weight: "bold"),
      tw("rs2 (counter)", size: 8pt),
    ) + 2 * pad
  let wr = calc.max(
      tw("pc <- done", font: mono, weight: "bold"),
      tw("taken", size: 8pt),
      tw("pc <- pc + 4", font: mono, weight: "bold"),
      tw("fall-through", size: 8pt),
    ) + 2 * pad

  let yb = boxh / 2
  let yt = boxh + vgap + boxh / 2
  let cy = (yb + yt) / 2
  let cx = wl + gap + hw
  let xr = cx + hw + gap
  let dx = hw * (1 - (yt - cy) / hh)

  canvas(length: 1pt, {
    import draw: *

    let box(x0, y, w, primary, secondary) = {
      rect((x0, y - boxh / 2), (x0 + w, y + boxh / 2), stroke: 0.8pt + luma(130), fill: white)
      content((x0 + w / 2, y + texth / 2 - lh1 / 2), text(primary, font: mono, weight: "bold"))
      content((x0 + w / 2, y + texth / 2 - lh1 - lead - lh2 / 2), text(secondary, size: 8pt))
    }

    // Arrows first: each end overshoots its target by 3.5pt so the boxes and
    // diamond painted on top hide the spill and the head meets the border.
    line((wl, yt), (cx - dx + 1.2, yt), stroke: 0.9pt + teal, mark: (end: (symbol: ">", fill: teal)))
    line((wl, yb), (cx - dx + 1.2, yb), stroke: 0.8pt + luma(110), mark: (end: (symbol: ">", fill: luma(110))))
    line((cx + dx - 1.2, yt), (xr + 1.2, yt), stroke: 0.9pt + teal, mark: (end: (symbol: ">", fill: teal)))
    line((cx + dx - 1.2, yb), (xr + 1.2, yb), stroke: 0.8pt + luma(110), mark: (end: (symbol: ">", fill: luma(110))))

    box(0, yt, wl, "t1 = 10", "rs1 (limit)")
    box(0, yb, wl, "t0 = i", "rs2 (counter)")
    box(xr, yt, wr, "pc <- done", "taken")
    box(xr, yb, wr, "pc <- pc + 4", "fall-through")

    line(
      (cx, cy + hh), (cx + hw, cy), (cx, cy - hh), (cx - hw, cy),
      close: true, stroke: 0.9pt + teal, fill: tealfill,
    )
    content((cx, cy + texth / 2 - lh1 / 2), text("blt t1, t0", font: mono, weight: "bold"))
    content((cx, cy + texth / 2 - lh1 - lead - lh2 / 2), text("10 < i ?", size: 8pt))

    content((cx + hw - 6, yt + 9), text("yes", size: 8.5pt))
    content((cx + hw - 6, yb - 9), text("no", size: 8.5pt))
  })
}

| Register      | ABI name | Role                      |
|---------------+----------+---------------------------|
| x0            | zero     | hardwired 0               |
| x1            | ra       | return address            |
| x2            | sp       | stack pointer             |
| x10–x17       | a0–a7    | arguments, ecall services |
| x5–x7, x28–31 | t0–t6    | caller-saved temporaries  |
| x8–x9, x18–27 | s0–s11   | callee-saved              |

* =ecall= services and =x0= immutability

Load a service code into =a7= (=1= print int, =4= print string, =11= print char, =10= or =93= exit), place its argument in =a0=, and execute =ecall=.

#+NAME: hello
#+BEGIN_SRC riscv
        .text
hello:
        addi    zero, zero, 99 # writes to x0 are silently dropped
        la      a0, msg        # a0 <- address of msg in .data
        li      a7, 4          # service 4: print NUL-terminated string
        ecall
        li      a0, 10         # '\n'
        li      a7, 11         # service 11: print char
        ecall
        li      a0, 0          # exit code 0
        li      a7, 10         # service 10: exit
        ecall

        .data
msg:
        .asciz "Hello, RISC-V!"
#+END_SRC

#+RESULTS:
: Hello, RISC-V!

*Try editing:* step past line 3 (=addi zero, zero, 99=) and confirm =zero= stays =0= in *Registers*. Notice in *Disassembly* that every instruction address steps by exactly 4 bytes, and =la a0, msg= expands into two 4-byte instructions.

* Watching the *Branch* panel in a loop

This loop sums $sum_(i=1)^10 i = 55$ in =t2=. Click the gutter on line 9 (=blt t1, t0, done=) to set a breakpoint, then press *Run* a few times: the *Branch* panel displays the two compared registers (=t1= and =t0=) and flips from *not taken* to *taken* on the eleventh check when =t0= reaches =11=.

#+NAME: sum-loop
#+BEGIN_SRC riscv
        .text
        li      t0, 1          # i = 1
        li      t1, 10         # limit = 10
        li      t2, 0          # sum = 0
loop:
        add     t2, t2, t0     # sum += i
        addi    t0, t0, 1      # i++
        blt     t1, t0, done   # branch if 10 < i
        j       loop
done:
        mv      a0, t2         # a0 = 55
        li      a7, 1          # service 1: print int
        ecall
        li      a0, 10         # '\n'
        li      a7, 11
        ecall
        li      a0, 0
        li      a7, 10         # exit
        ecall
#+END_SRC

#+RESULTS:
: 55

*Try editing:* change =blt t1, t0, done= to =bge t0, t1, done= and re-run — the loop now stops one iteration early at =45= because it exits when $i = 10$ before adding $10$.

* Sign extension vs zero extension (=lb= vs =lbu=)

When a 32-bit RISC-V core loads a single byte from memory, it has to fill the upper 24 bits of the destination register. =lb= copies bit 7 (the sign bit) into bits 8–31, preserving two's-complement negative numbers; =lbu= fills bits 8–31 with zeros.

Run =bytes= and inspect *.data*: =sw t0, 0(t1)= writes four =FF= bytes into =buf=, then =lb= and =lbu= read the very same address =0(t1)= into =a0= with opposite interpretations.

#+NAME: bytes
#+BEGIN_SRC riscv
        .text
        li      t0, -1         # 0xFFFFFFFF in two's complement
        la      t1, buf        # t1 -> scratch word in .data
        sw      t0, 0(t1)      # store FF FF FF FF
        lb      a0, 0(t1)      # sign-extend 0xFF -> 0xFFFFFFFF (-1)
        li      a7, 1
        ecall
        li      a0, 32         # ' '
        li      a7, 11
        ecall
        lbu     a0, 0(t1)      # zero-extend 0xFF -> 0x000000FF (255)
        li      a7, 1
        ecall
        li      a0, 10         # '\n'
        li      a7, 11
        ecall
        li      a0, 0
        li      a7, 10
        ecall

        .data
buf:
        .word 0
#+END_SRC

#+RESULTS:
: -1 255

*Try editing:* change =li t0, -1= to =li t0, 127= (=0x7F=, sign bit 0) and re-run — both loads print =127=. Change it to =128= (=0x80=, sign bit 1) and watch =lb= jump to =-128= while =lbu= prints =128=.
