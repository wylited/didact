#+TITLE: Typst in the Browser
#+SUBTITLE: Real Typst 0.15 compiled to WebAssembly — edit markup, render vector pages locally

Typst is a modern, compiled typesetting language — like LaTeX, but with clean syntax and fast compilation. Every block on this page compiles locally in your browser using the real *Typst 0.15* WebAssembly engine, with nothing sent to a server.

How blocks work here:

- *Compile & render:* Clicking *Run* compiles the block and shows the rendered vector page, page count, compile time, and any warnings in the right-hand panel. (There is no single-stepping because typesetting is a single compile pass.)
- *Independent blocks:* Each block compiles on its own and sets =width: auto, height: auto= so the rendered page hugs its content. Syntax errors highlight the exact line in red.

* Inline math in prose

Wrap math in =$...$= to place formulas right inside a sentence. Typst handles roots, exponents, and baseline alignment automatically without verbose backslash commands.

#+NAME: pythagoras
#+BEGIN_SRC typst
#set page(width: auto, height: auto, margin: 1em)

In the plane, the distance from the origin to $(x, y)$ is
$root(2, x^2 + y^2)$, and for the sides of a right triangle
Euclid gives us $x^2 + y^2 = z^2$.
#+END_SRC

#+RESULTS:
: one page: the sentence with $sqrt(x^2+y^2)$ and $x^2 + y^2 = z^2$ typeset

* Styled tables with code

Layout elements in Typst are ordinary functions. Here =#table= accepts =columns=, =inset=, and a small alignment function =(x, y) => ...= that centers row 0 (the header) and right-aligns every data cell.

#+NAME: primes
#+BEGIN_SRC typst
#set page(width: auto, height: auto, margin: 1em)

#table(
  columns: (auto, auto, auto),
  inset: 6pt,
  align: (x, y) => if y == 0 { center } else { right },
  table.header([*n*], [*n^2*], [*n^3*]),
  [2], [$2^2 = 4$],   [$2^3 = 8$],
  [3], [$3^2 = 9$],   [$3^3 = 27$],
  [5], [$5^2 = 25$],  [$5^3 = 125$],
)
#+END_SRC

#+RESULTS:
: one page: a 4-row table, centered bold header, right-aligned cells

* Headings, rules, and numbered proofs

=#set= rules configure styling globally for the rest of the document — below, =#set enum(numbering: "i.")= switches =+= numbered lists to lowercase Roman numerals, while === creates a heading and =*...*= marks bold text.

#+NAME: euclid
#+BEGIN_SRC typst
#set page(width: auto, height: auto, margin: 1em)
#set enum(numbering: "i.")

= The Infinitude of Primes

*Theorem.* There are infinitely many prime numbers.

+ Suppose the primes were finite: $p_1, p_2, dots.c, p_n$.
+ Let $N = p_1 p_2 dots.c p_n + 1$, one larger than their product.
+ Some prime divides $N$ — but no $p_i$ does, since each leaves remainder $1$.
+ So a prime exists outside the list: contradiction.
#+END_SRC

#+RESULTS:
: one page: heading, theorem statement, roman-numbered four-step proof

Try deleting one closing =$= above and clicking *Run*: Typst reports an /unclosed delimiter/ on the exact line while leaving the other blocks unaffected.
