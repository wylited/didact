#+TITLE: Typst, Live and Prebuilt
#+SUBTITLE: Real Typst 0.15 on both sides of the build: prebuilt MathML/SVG figures in prose, and live editable Typst blocks in the browser

Didact uses the exact same Typst 0.15 compiler in two distinct layers. Everything written as prose math (=$...$= / =$$...$$=) or a =#+BEGIN_SRC typst :results svg= block is compiled once at *build time* and shipped as static MathML and inline SVG — zero engine download, zero click required. Any plain =#+BEGIN_SRC typst= block (without =:results svg=) is an *interactive kernel block* compiled locally in your browser via [[file:wasm.org][WebAssembly]], rendering the live vector page, page count, compile time, and line-mapped diagnostics in the right-hand panel.

* Build-time prose math and notebook figures

Inline math compiles to accessible, selectable MathML before the page ever ships: $sum_(k=1)^n k = (n(n+1))/2$, $e^(i pi) + 1 = 0$, and $norm(v) = sqrt(v_1^2 + v_2^2 + dots.c + v_n^2)$. Display equations sit on their own line:

$$ integral_0^1 x^2 dif x = 1/3 quad "and" quad sum_(k=0)^oo 1/2^k = 2 $$

Static diagram blocks (=:results svg=) can import any =@preview= package — the diagrams interleaved across every lesson on this site use =fletcher= (flowcharts/graphs), =lilaq= (data plots), and =cetz= (Cartesian geometry).

* Live kernel: functional tables with =#table=

In Typst, layout elements are ordinary functions. Here ~align: (x, y) => if y == 0 { center } else { right }~ computes cell alignment dynamically from each cell's column =x= and row =y=.

#+NAME: live-table
#+BEGIN_SRC typst
#set page(width: auto, height: auto, margin: 1em)

#table(
  columns: (auto, auto, auto),
  inset: 6pt,
  align: (x, y) => if y == 0 { center } else { right },
  table.header([*n*], [*$n^2$*], [*$n^3$*]),
  [2], [$4$],   [$8$],
  [3], [$9$],   [$27$],
  [5], [$25$],  [$125$],
  [7], [$49$],  [$343$],
)
#+END_SRC

* Live kernel: scoped =#set= rules and proofs

=#set= rules cascade over everything that follows in the current scope. Here =#set enum(numbering: "i.")= turns =+= items into lowercase Roman numerals.

#+NAME: live-proof
#+BEGIN_SRC typst
#set page(width: auto, height: auto, margin: 1em)
#set enum(numbering: "i.")

= The Infinitude of Primes

*Theorem.* There are infinitely many prime numbers.

+ Suppose the primes were finite: $p_1, p_2, dots.c, p_n$.
+ Let $N = p_1 p_2 dots.c p_n + 1$, one larger than their product.
+ Some prime divides $N$, yet no $p_i$ does (each leaves remainder $1$).
+ Therefore a prime exists outside the list: contradiction.
#+END_SRC

#+RESULTS:
: one page: heading, theorem statement, and Roman-numbered proof

*Try editing:* change =numbering: "i."= to =numbering: "(a)"= and re-run to restyle every proof step in one line.
