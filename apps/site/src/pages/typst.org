#+TITLE: Typst in the Browser
#+SUBTITLE: Real Typst 0.15 compiled to WebAssembly, rendering vector pages locally

Each block on this page compiles locally with the real Typst 0.15 compiler running as [[file:wasm.org][WebAssembly]]. Click Run and the right-hand panel renders the vector page along with page count, compile time, and any compiler warnings. Each block compiles independently with =width: auto, height: auto= so the page fits tightly around the output.

* Math inline with prose

Wrap formulas in =$...$= to embed math directly in a sentence without LaTeX's backslash noise.

#+NAME: pythagoras
#+BEGIN_SRC typst
#set page(width: auto, height: auto, margin: 1em)

In the plane, the distance from the origin to $(x, y)$ is
$root(2, x^2 + y^2)$, and for the sides of a right triangle
Euclid gives us $x^2 + y^2 = z^2$.
#+END_SRC

#+RESULTS:
: one page: the sentence with $sqrt(x^2+y^2)$ and $x^2 + y^2 = z^2$ typeset

* Tables styled with functions

=#table= is a normal Typst function call. Here =align: (x, y) => if y == 0 { center } else { right }= centers the header row and right-aligns the numeric cells below it.

#+NAME: primes
#+BEGIN_SRC typst
#set page(width: auto, height: auto, margin: 1em)

#table(
  columns: (auto, auto, auto),
  inset: 6pt,
  align: (x, y) => if y == 0 { center } else { right },
  table.header([*n*], [*n^2*], [*n^3*]),
  [2], [$2^2 = 4$],   [$2^3 = 8$],
  [3], [$3^2 = 9$],   [$3^3 = 27$],
  [5], [$5^2 = 25$],  [$5^3 = 125$],
)
#+END_SRC

#+RESULTS:
: one page: a 4-row table, centered bold header, right-aligned cells

* Document rules and numbered proofs

=#set= rules apply formatting across the rest of the block. Here =#set enum(numbering: "i.")= turns the =+= list into lowercase Roman numerals, while === marks a heading and =*...*= makes text bold.

#+NAME: euclid
#+BEGIN_SRC typst
#set page(width: auto, height: auto, margin: 1em)
#set enum(numbering: "i.")

= The Infinitude of Primes

*Theorem.* There are infinitely many prime numbers.

+ Suppose the primes were finite: $p_1, p_2, dots.c, p_n$.
+ Let $N = p_1 p_2 dots.c p_n + 1$, one larger than their product.
+ Some prime divides $N$ — but no $p_i$ does, since each leaves remainder $1$.
+ So a prime exists outside the list: contradiction.
#+END_SRC

#+RESULTS:
: one page: heading, theorem statement, roman-numbered four-step proof

Try deleting a closing =$= and running again: Typst pins the /unclosed delimiter/ error to the exact line while leaving the other blocks alone.
