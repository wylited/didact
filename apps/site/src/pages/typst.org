#+TITLE: Typst in the Browser
#+SUBTITLE: Real Typst 0.15 compiled to WebAssembly, rendering vector pages locally

Each block on this page compiles locally with the real Typst 0.15 compiler running as WebAssembly. Click Run and the right-hand panel renders the vector page along with page count, compile time, and any compiler warnings. Each block compiles independently with =width: auto, height: auto= so the page fits tightly around the output.

* Math inline with prose

Wrap formulas in =$...$= to embed math directly in a sentence without LaTeX's backslash noise.

#+NAME: pythagoras
#+BEGIN_SRC typst
#set page(width: auto, height: auto, margin: 1em)

In the plane, the distance from the origin to $(x, y)$ is
$root(2, x^2 + y^2)$, and for the sides of a right triangle
Euclid gives us $x^2 + y^2 = z^2$.
#+END_SRC

#+RESULTS:
: one page: the sentence with $sqrt(x^2+y^2)$ and $x^2 + y^2 = z^2$ typeset

* Tables styled with functions

=#table= is a normal Typst function call. Here =align: (x, y) => if y == 0 { center } else { right }= centers the header row and right-aligns the numeric cells below it.

#+NAME: primes
#+BEGIN_SRC typst
#set page(width: auto, height: auto, margin: 1em)

#table(
  columns: (auto, auto, auto),
  inset: 6pt,
  align: (x, y) => if y == 0 { center } else { right },
  table.header([*n*], [*n^2*], [*n^3*]),
  [2], [$2^2 = 4$],   [$2^3 = 8$],
  [3], [$3^2 = 9$],   [$3^3 = 27$],
  [5], [$5^2 = 25$],  [$5^3 = 125$],
)
#+END_SRC

#+RESULTS:
: one page: a 4-row table, centered bold header, right-aligned cells

* Document rules and numbered proofs

=#set= rules apply formatting across the rest of the block. Here =#set enum(numbering: "i.")= turns the =+= list into lowercase Roman numerals, while === marks a heading and =*...*= makes text bold.

#+NAME: euclid
#+BEGIN_SRC typst
#set page(width: auto, height: auto, margin: 1em)
#set enum(numbering: "i.")

= The Infinitude of Primes

*Theorem.* There are infinitely many prime numbers.

+ Suppose the primes were finite: $p_1, p_2, dots.c, p_n$.
+ Let $N = p_1 p_2 dots.c p_n + 1$, one larger than their product.
+ Some prime divides $N$ — but no $p_i$ does, since each leaves remainder $1$.
+ So a prime exists outside the list: contradiction.
#+END_SRC

#+RESULTS:
: one page: heading, theorem statement, roman-numbered four-step proof

Try deleting a closing =$= and running again: Typst pins the /unclosed delimiter/ error to the exact line while leaving the other blocks alone.

* Prose math, pre-rendered at build time

Inline math is Typst too: $sum_(k=1)^n k = (n(n+1))/2$, $e^(i pi) + 1 = 0$, and $norm(v) = sqrt(v_1^2 + v_2^2 + dots.c + v_n^2)$ all typeset with the same compiler as the blocks below, but before the page ships. The browser receives MathML, so the text stays selectable and accessible.

Display math gets its own line:

$$ integral_0^1 x^2 dif x = 1/3 quad "and" quad sum_(k=0)^oo 1/2^k = 2 $$

No engine download, no JavaScript, no font fetch: this paragraph is static HTML. The live blocks further down are a separate layer (the kernel) and still compile locally on Run.

* Diagrams, compiled to SVG

A typst block with =:results svg= is a diagram, not an editor: the build compiles it once and inlines the vector result. Everything else about the block is ordinary Typst, including package imports — any =@preview= package name resolves from the registry with no allowlist.

#+CAPTION: Four-stage pipeline with feedback
#+BEGIN_SRC typst :results svg
#set text(size: 10pt)
#import "@preview/fletcher:0.5.8": diagram, node, edge

#let stage(pos, body) = node(
  pos, body,
  shape: rect, inset: 6pt, width: 64pt,
  stroke: 0.8pt + rgb("#1A9988"), fill: white,
)
#let wire(from, to, marks: "->", label: none) = edge(
  from, to, marks,
  stroke: 0.9pt + rgb("#1A9988"),
  label: label, label-pos: 50%, label-sep: 4pt, label-fill: white,
)

#diagram(
  stage((0, 0), [source]),
  stage((1, 0), [parse]),
  stage((2, 0), [emit]),
  stage((3, 0), [run]),
  wire((0, 0), (1, 0)),
  wire((1, 0), (2, 0)),
  wire((2, 0), (3, 0)),
  wire((3, 0), (3, -1), marks: "-"),
  wire((3, -1), (0, -1), marks: "-", label: [feedback]),
  wire((0, -1), (0, 0)),
)
#+END_SRC

A plot is the same mechanism with a different package: =@preview/lilaq= computes the samples at compile time, and the SVG reaches the page as geometry.

#+CAPTION: Damped oscillation plot
#+BEGIN_SRC typst :results svg
#set text(size: 10pt)
#import "@preview/lilaq:0.6.0" as lq

#let xs = lq.linspace(0, 4, num: 41)
#let ys = xs.map(t => calc.exp(-t / 1.6) * calc.sin(2 * calc.pi * 0.9 * t))

#lq.diagram(
  width: 9cm, height: 4.5cm,
  xlabel: [$t$], ylabel: [$v$],
  xaxis: (ticks: (0, 1, 2, 3, 4), subticks: none),
  lq.plot(xs, ys, mark: none, stroke: rgb("#1A9988")),
)
#+END_SRC

A third package, a third output style: =@preview/cetz= draws the same page with a Cartesian canvas, so a geometry figure is a handful of coordinates rather than a plotted function.

#+CAPTION: Geometry on a Cartesian canvas
#+BEGIN_SRC typst :results svg
#set text(size: 10pt)
#import "@preview/cetz:0.5.2": canvas, draw

#canvas(length: 1.6cm, {
  import draw: *
  grid((0, 0), (4, 2.4), step: 1, stroke: 0.3pt + luma(210))
  line((0, 0), (3.6, 2.2), stroke: 0.9pt + rgb("#1A9988"))
  circle((1.8, 1.1), radius: 0.7, stroke: 0.9pt + rgb("#1A9988"))
  line((1.8, 1.1), (2.5, 1.1), stroke: (paint: rgb("#8A5A44"), thickness: 0.7pt, dash: "dashed"))
  content((2.15, 1.16), [$r$], anchor: "south")
  content((3.6, 2.2), [end], anchor: "south-west")
})
#+END_SRC

* Executable blocks stay interactive

The block below has no =:results= header, so it remains a kernel block: edit it, press Run, and the panel shows the compiled page. Same language, same packages, different lifecycle — the build-time layer and the in-browser layer never share a session.

#+BEGIN_SRC typst
#set page(width: auto, height: auto, margin: 1em)
$ integral_(-oo)^(+oo) e^(-x^2) dif x = sqrt(pi) $
#+END_SRC
