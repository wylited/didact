* RAII: scope is your cleanup

In C++, destructors run automatically when a local variable leaves scope — and always in *reverse order of construction*. Below, =outer= is built first and =inner= second, so =inner= is destroyed the moment the inner ={ ... }= block ends, before =outer= is touched. That deterministic lifetime is how C++ manages files, locks, and memory without a garbage collector or =finally= blocks.

#+NAME: raii
#+BEGIN_SRC cpp
#include <cstdio>

struct Trace {
  const char* name;
  explicit Trace(const char* n) : name(n) {
    std::printf("construct %s\n", name);
  }
  ~Trace() { std::printf("destroy %s\n", name); }
};

int main() {
  Trace outer("outer");
  {
    Trace inner("inner");
    std::printf("--- inner scope ends ---\n");
  }
  std::printf("--- inner already gone ---\n");
  return 0;
}
#+END_SRC

#+RESULTS:
: construct outer
: construct inner
: --- inner scope ends ---
: destroy inner
: --- inner already gone ---
: destroy outer

* =std::vector= doubles its capacity

When =push_back= runs out of room, =std::vector= allocates a new buffer (typically 2x larger), moves the existing elements over, and frees the old buffer. Watch =capacity= jump =1 -> 2 -> 4 -> 8= while =size= grows by 1 each step. On the fourth push, =capacity= stays at 4 because there is already room — that geometric growth is why =push_back= is *O(1) amortized*.

#+NAME: vector-growth
#+BEGIN_SRC cpp
#include <vector>
#include <cstdio>

int main() {
  std::vector<int> v;
  for (int i = 1; i <= 5; i++) {
    v.push_back(i * i);
    std::printf("push %2d: size=%zu capacity=%zu\n", i * i, v.size(), v.capacity());
  }
  for (size_t i = 0; i < v.size(); ++i)
    std::printf(i == 0 ? "%d" : " %d", v[i]);
  std::printf("\n");
  return 0;
}
#+END_SRC

#+RESULTS:
: push  1: size=1 capacity=1
: push  4: size=2 capacity=2
: push  9: size=3 capacity=4
: push 16: size=4 capacity=4
: push 25: size=5 capacity=8
: 1 4 9 16 25

* Templates: compile-time code generation

A C++ template is not a runtime generic with boxing or dynamic dispatch. Each time you call =max= with a new type (=int=, =double=, =char=), the compiler stamps out a separate, specialized machine-code function for that exact type.

#+NAME: templates
#+BEGIN_SRC cpp
#include <cstdio>

template <typename T>
T max(T a, T b) {
  return a > b ? a : b;
}

int main() {
  std::printf("max(3, 9)        = %d\n", max(3, 9));
  std::printf("max(2.5, 2.25)   = %.1f\n", max(2.5, 2.25));
  std::printf("max('a', 'z')    = %c\n", max('a', 'z'));
  return 0;
}
#+END_SRC

#+RESULTS:
: max(3, 9)        = 9
: max(2.5, 2.25)   = 2.5
: max('a', 'z')    = z

* References vs pointers

Both functions below swap two integers, but they express different contracts:

- =int&= (reference): must bind to a real variable, cannot be null, and cannot be rebound later. Callers pass =x, y= directly.
- =int*= (pointer): holds an explicit memory address, can be null, and requires =&= at the call site and =*= inside the function.

#+NAME: refs-vs-pointers
#+BEGIN_SRC cpp
#include <cstdio>

void swapRef(int& a, int& b) {
  int t = a; a = b; b = t;
}

void swapPtr(int* a, int* b) {
  int t = *a; *a = *b; *b = t;
}

int main() {
  int x = 1, y = 2;
  swapRef(x, y);
  std::printf("after swapRef(x, y): x=%d y=%d\n", x, y);
  swapPtr(&x, &y);
  std::printf("after swapPtr(&x, &y): x=%d y=%d\n", x, y);
  return 0;
}
#+END_SRC

#+RESULTS:
: after swapRef(x, y): x=2 y=1
: after swapPtr(&x, &y): x=1 y=2

* Lambdas: value capture vs reference capture

A lambda's capture list =[...]= decides whether it copies a variable or points to the original:

- =[base]= snapshots =base= (10) when the lambda is created. Changing =base = 100= later has zero effect on =addBase=.
- =[&counter]= captures a reference to =counter=, so every call to =bump()= mutates the live variable.

#+NAME: lambdas
#+BEGIN_SRC cpp
#include <cstdio>

int main() {
  int base = 10;
  auto addBase = [base](int x) { return base + x; };
  int counter = 0;
  auto bump = [&counter]() { ++counter; };

  std::printf("addBase(5) = %d\n", addBase(5));
  bump();
  bump();
  bump();
  std::printf("counter after 3 bumps = %d\n", counter);
  base = 100;
  std::printf("after base = 100, addBase(5) = %d (copied at capture!)\n", addBase(5));
  return 0;
}
#+END_SRC

#+RESULTS:
: addBase(5) = 15
: counter after 3 bumps = 3
: after base = 100, addBase(5) = 15 (copied at capture!)
