#+SUBTITLE: Tables, multiple returns, 1-based arrays, and metatables in a steppable Lua 5.4 subset

* Everything is a table

Lua has no separate list, dict, or object type. Everything is a /table/: an associative map that also stores consecutive integer keys starting at =1= as an array. A single table like ={10, 20, 30, name = "xs"}= holds both at the same time.

Step through the block below with the *Tables* panel open. Array slots appear first (=t[1]=, =t[2]=, ...), hash entries below them, and =Δ= marks whatever the last step wrote. (There is no garbage collector in this interpreter, so allocated tables stay visible in the panel.) The =#= operator counts consecutive integer keys from =1= and ignores the hash part.

#+NAME: tables-101
#+BEGIN_SRC lua
local t = {10, 20, 30, name = "xs"}
t[4] = 40
t.lang = "lua"
print(#t, t[1], t.name, t.lang)
#+END_SRC

#+RESULTS:
: 4	10	xs	lua

=ipairs(t)= walks integer keys =1, 2, 3, ...= until the first =nil=. =pairs(t)= walks everything in the table, array entries first and hash keys after.

#+NAME: tables-pairs
#+BEGIN_SRC lua
local t = {10, 20, name = "xs"}
for i, v in ipairs(t) do print(i, v) end
for k, v in pairs(t) do print(k, v) end
#+END_SRC

#+RESULTS:
: 1	10
: 2	20
: 1	10
: 2	20
: name	xs

* Multiple returns and parallel assignment

Functions in Lua can return several values directly. If a call is the last thing on the right side of an assignment (=local lo, hi = minmax(xs)=), it expands to all its return values. If there is only one variable on the left (=local only = minmax(xs)=), the extra return values are dropped. Wrapping a call in parentheses =(minmax(xs))= forces it down to one value even in a list like =print(...)=.

Since Lua evaluates the entire right-hand side before writing anything on the left, swapping two variables is just =a, b = b, a=.

#+NAME: multiple-returns
#+BEGIN_SRC lua
local function minmax(t)
  local lo, hi = t[1], t[1]
  for i = 2, #t do
    if t[i] < lo then lo = t[i] end
    if t[i] > hi then hi = t[i] end
  end
  return lo, hi
end
local xs = {3, 1, 4, 1, 5}
local lo, hi = minmax(xs)
local only = minmax(xs)
print(lo, hi, only, (minmax(xs)))
a, b = 1, 2
a, b = b, a
print(a, b)
#+END_SRC

#+RESULTS:
: 1	5	1	1
: 2	1

* Truthiness and 1-based indexing

If you mostly write Python, C, or JS, two things in Lua will catch you off guard: =0= and =""= are both truthy (only =nil= and =false= are falsy), and arrays start at index =1= (=t[0]= is just =nil=).

#+NAME: truth-and-one
#+BEGIN_SRC lua
if 0 then print("0 is truthy") end
if "" then print("the empty string is truthy") end
if nil or false then print("never") else print("only nil and false are falsy") end
local t = {"a", "b", "c"}
print(t[1], t[0], #t)
#+END_SRC

#+RESULTS:
: 0 is truthy
: the empty string is truthy
: only nil and false are falsy
: a	nil	3

* Integers vs floats

Lua 5.4 tracks integers (=1=) and floats (=1.0=) separately. =/= always gives a float (=7 / 2 = 3.5=). =//= is floor division toward negative infinity, so =-7 // 2= is =-4=, not =-3=. Modulo =%= takes the sign of the divisor (=5 % -3 = -1=). Numerically equal values still compare equal (=1 == 1.0= is =true=).

Because this interpreter runs on JavaScript numbers instead of 64-bit C integers, literals past =2^53= are rejected at load time rather than silently rounded.

#+NAME: ints-and-floats
#+BEGIN_SRC lua
print(1, 1.0, 7 / 2)
print(7 // 2, 7.0 // 2, -7 // 2)
print(5 % 3, 5 % -3, -5 % 3)
print(1 == 1.0)
#+END_SRC

#+RESULTS:
: 1	1.0	3.5
: 3	3.0	-4
: 2	-1	1
: true

* Inheritance with metatables

Lua has no =class= keyword. Instead, you attach a metatable with an =__index= field. When a key lookup misses on a table, Lua checks =__index=: if it is another table, lookup continues there (and can chain multiple levels up); if it is a function, Lua calls it with =(table, key)=.

The colon syntax just hides =self=: =rex:greet()= is identical to =rex.greet(rex)=, and =function Animal:greet()= implicitly adds =self= as the first argument.

#+NAME: metatables
#+BEGIN_SRC lua
local Animal = {}
function Animal:greet() return self.sound .. "!" end
local Dog = {}
Animal.__index = Animal
setmetatable(Dog, {__index = Animal})
local Dog2 = {}
Dog.__index = Dog
setmetatable(Dog2, {__index = Dog})
local rex = {sound = "woof"}
setmetatable(rex, {__index = Dog2})   -- two levels up to Animal
local fallback = setmetatable({}, {__index = function(t, k) return k .. "?" end})
print(rex:greet())
print(fallback.anything)
#+END_SRC

#+RESULTS:
: woof!
: anything?
