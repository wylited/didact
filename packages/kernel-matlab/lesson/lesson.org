#+TITLE: MATLAB, Column-Major
#+SUBTITLE: Matrices, linear indexing, backslash solving, workspaces, and vectorization on a steppable interpreter

This is a small MATLAB-flavored interpreter written in TypeScript. Every value is a 2D matrix of IEEE 754 doubles stored column-major in a flat array, just like real MATLAB. It covers matrix literals, ranges, matrix and elementwise operators, =end= indexing, control flow, top-level functions, and core builtins (=zeros=, =sum=, =sort=, =det=, =inv=). Cells, structs, function handles, =try/catch=, and string variables are rejected with their line number.

A few small quirks of this subset: there is no =rand= (everything is deterministic), numbers trim trailing zeros (=0.5= instead of =0.5000=), and inside =[ ]= a minus sign starts a new element, so write =[(1 - 2)]= for subtraction.

* Column-major storage and linear indexing

Inside =[ ... ]=, spaces or commas separate columns and semicolons start new rows.

#+BEGIN_SRC matlab
A = [1 2; 3 4]
disp(A(:)')
disp(A(2))
disp(A(3))
#+END_SRC

#+RESULTS:
: A =
:
: 1  2
: 3  4
: 1  3  2  4
: 3
: 2

Notice =A(2)= is =3= and =A(3)= is =2=. That happens because MATLAB lays =[1 2; 3 4]= out down the first column and then down the second: =[1, 3, 2, 4]=. Hit Step and open the *Matrices* panel to see every element at its flat 0-based address (=(col - 1) * rows + row - 1=) along with its raw 64-bit IEEE 754 hex bytes.

Ranges (=start:step:stop=) build row vectors, and a trailing semicolon suppresses printing:

#+BEGIN_SRC matlab
v = 1:0.5:3
disp(v)
w = 5:-2:1;
disp(w)
#+END_SRC

#+RESULTS:
: v =
:
:   1  1.5    2  2.5    3
:   1  1.5    2  2.5    3
: 5  3  1

* Matrix math vs elementwise math

Bare =*= does matrix multiplication; dotted =.*= multiplies element by element. The same split applies to =/= and =\= (linear solves) vs =./= and =.\= (elementwise division), and =^= vs =.^=. ='= transposes.

#+BEGIN_SRC matlab
A = [1 2; 3 4];
B = [5 6; 7 8];
disp(A * B)
disp(A .* B)
#+END_SRC

#+RESULTS:
: 19  22
: 43  50
:  5  12
: 21  32

* Solving =Mx = b= with =\=

Backslash (=M \ b=) runs Gaussian elimination with partial pivoting instead of explicitly inverting =M=. Here one backslash fits a quadratic =p(x) = a + bx + cx^2= through =(1, 6)=, =(2, 14)=, and =(3, 36)=, giving =12 - 13x + 7x^2=. If =M= is singular, both =\= and =inv= stop with an error on that line.

#+BEGIN_SRC matlab
M = [1 1 1; 1 2 4; 1 3 9];
b = [6; 14; 36];
c = M \ b;
disp(c')
#+END_SRC

#+RESULTS:
:  12  -13    7

* Slicing and deleting rows or columns

Indexing starts at 1, =:= means the whole row or column, and =end= is the length of that dimension. Assigning =[]= to a full row or column deletes it; watch the remaining elements slide to new addresses in the *Matrices* panel when =A(:, 2) = []= runs. Out-of-bounds writes are rejected (preallocate with =zeros=).

#+BEGIN_SRC matlab
A = [1 2 3; 4 5 6];
disp(A(1:2, 2:end))
disp(A(:, 2))
disp(A(1, :))
A(1, :) = [10 20 30];
A(:, 2) = [];
disp(A)
#+END_SRC

#+RESULTS:
: 2  3
: 5  6
: 2
: 5
: 1  2  3
: 10  30
:  4   6

* Functions get their own workspace

Arguments are passed by value, and local variables inside a function never leak into the script's workspace. Here =y= lives inside =twice= and never shows up next to =v= in the *Workspace* panel. Put a breakpoint on line 3 to see =twice='s private workspace in the *Call stack* panel. Functions can also return multiple outputs (=function [q, r] = divmod(a, b)=).

#+BEGIN_SRC matlab
function t = twice(x)
  y = x * 2;
  t = y;
end
v = [1 2 3];
w = twice(v);
fprintf('v is still %d %d %d\n', v(1), v(2), v(3));
fprintf('w is      %d %d %d\n', w(1), w(2), w(3));
#+END_SRC

#+RESULTS:
: v is still 1 2 3
: w is      2 4 6

=fprintf= accepts literal format strings with =%d=, =%.Nf=, =%%=, and =\n= (strings are display-only in this dialect).

* Loops vs vectorization

In MATLAB, =for c = A= loops over the *columns* of =A= (=[1; 4]=, then =[2; 5]=, then =[3; 6]=). Both approaches below print =21=, but =sum(sum(A))= pushes the whole walk into builtins instead of stepping through every loop iteration in the interpreter. (=sum(A)= sums down columns; =sum(A, 2)= sums across rows.)

#+BEGIN_SRC matlab
A = [1 2 3; 4 5 6];
s = 0;
for c = A
  s = s + sum(c);
end
fprintf('loop total:      %d\n', s);
fprintf('vectorized total: %d\n', sum(sum(A)));
#+END_SRC

#+RESULTS:
: loop total:      21
: vectorized total: 21
