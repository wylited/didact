#+TITLE: C in the Browser
#+SUBTITLE: Real clang compiling to wasm32-wasi right in this tab

These blocks compile with actual clang (LLVM 22 via =@yowasp/clang=) and run in your browser's WebAssembly engine. The first run pulls down the ~105 MB toolchain once and caches it locally. After that, hitting Run compiles, links with =wasm-ld=, and executes the binary in the same tab.

WebAssembly cannot talk to your OS directly, so a small WASI shim handles stdout/stderr, exit codes, random bytes, and wall-clock time. Anything else (files, sleep, spawning processes) stops with an explicit unsupported-call error. Keep an eye on the panel on the right: it shows the compiler output, exit code, binary size, compile time, and the first 256 bytes of the linked =.wasm= file. One catch: a tight infinite loop with no I/O will freeze the tab because raw WebAssembly cannot be preempted.

* =puts= and =printf=

=puts= writes a string and tacks on a newline for you. =printf= gives you format strings like =%d= and leaves the newline up to you. Try deleting a semicolon and hitting Run to see clang report the exact line.

#+NAME: hello
#+BEGIN_SRC c
#include <stdio.h>

int main(void) {
  puts("Hello, world!");
  printf("2 + 3 = %d\n", 2 + 3);
  return 0;
}
#+END_SRC

#+RESULTS:
: Hello, world!
: 2 + 3 = 5

* Summing 1 through 10

A basic =for= loop summing the first ten integers into =sum=.

#+NAME: sum-loop
#+BEGIN_SRC c
#include <stdio.h>

int main(void) {
  int sum = 0;
  for (int i = 1; i <= 10; i++) sum += i;
  printf("%d\n", sum);
  return 0;
}
#+END_SRC

#+RESULTS:
: 55

* Recursive =factorial(10)=

Standard recursive factorial using =long=. Because =wasm32= has 32-bit =long=s, =10!= fits fine (=3628800=), but changing =10= to =13= will overflow.

#+NAME: factorial
#+BEGIN_SRC c
#include <stdio.h>

long factorial(int n) {
  return n <= 1 ? 1L : n * factorial(n - 1);
}

int main(void) {
  printf("%ld\n", factorial(10));
  return 0;
}
#+END_SRC

#+RESULTS:
: 3628800
