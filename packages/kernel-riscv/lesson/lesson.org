#+TITLE: RISC-V (RV32IM) in an Afternoon
#+SUBTITLE: Fixed-width 32-bit instructions, ABI registers, and ecall on a steppable simulator

* The RV32IM register file

RISC-V keeps the core hardware simple: every instruction is 4 bytes wide, reads at most two registers, and writes at most one. The =M= extension adds integer multiply and divide. There are 32 registers (=x0=–=x31=), with =x0= (=zero=) hardwired to =0= so writes to it are discarded:

| Register      | ABI name | Role                      |
|---------------+----------+---------------------------|
| x0            | zero     | always 0                  |
| x1            | ra       | return address            |
| x2            | sp       | stack pointer             |
| x10–x17       | a0–a7    | arguments, ecall services |
| x5–x7, x28–31 | t0–t6    | caller-saved temporaries  |
| x8–x9, x18–27 | s0–s11   | callee-saved registers    |

Like MIPS, RISC-V has *no condition flags register*. Branch instructions like =blt= and =bne= compare two registers and jump in one instruction — watch the right-hand panel's *Branch context* to see the last comparison and whether it was taken.

* Talking to the environment with =ecall=

This simulator uses the Venus/RARS =ecall= convention: load a service number into =a7=, put any argument in =a0=, and execute =ecall=:

| =a7= | Service      | Effect                             |
|------+--------------+------------------------------------|
| 1    | print int    | print =a0= as a signed decimal     |
| 4    | print string | print NUL-terminated bytes at =a0= |
| 11   | print char   | print the low byte of =a0=         |
| 10   | exit         | stop execution                     |
| 93   | exit         | same as 10 (Linux exit syscall)    |

* Printing a string with =ecall=

=la= loads the address of =msg= into =a0=, and =li= loads the service number =4= into =a7=. Edit the string inside =.asciz= and click *Run* to see it update immediately.

#+NAME: hello
#+BEGIN_SRC riscv
        .text
hello:
        la      a0, msg        # a0 -> address of the string
        li      a7, 4          # service 4: print string
        ecall
        li      a0, 10         # '\n'
        li      a7, 11         # service 11: print char
        ecall
        li      a0, 0          # exit code 0
        li      a7, 10         # service 10: exit
        ecall

        .data
msg:
        .asciz "Hello, RISC-V!"
#+END_SRC

#+RESULTS:
: Hello, RISC-V!

* Counting loop: sum 1..10

Here =t0= is the loop counter (=1..10=), =t1= holds the limit (=10=), and =t2= accumulates the sum. Once =10 < t0=, =blt t1, t0, done= exits the loop and prints =55=. Single-step through a couple of iterations to watch =t0= and =t2= light up in the register panel.

#+NAME: sum-loop
#+BEGIN_SRC riscv
        .text
        li      t0, 1          # i = 1
        li      t1, 10         # limit = 10
        li      t2, 0          # sum = 0
loop:
        add     t2, t2, t0     # sum += i
        addi    t0, t0, 1      # i++
        blt     t1, t0, done   # if 10 < i, leave the loop
        j       loop
done:
        mv      a0, t2         # a0 = 55
        li      a7, 1          # service 1: print int
        ecall
        li      a0, 10         # newline
        li      a7, 11
        ecall
        li      a0, 0
        li      a7, 10         # exit
        ecall
#+END_SRC

#+RESULTS:
: 55

* Signed vs unsigned byte loads (=lb= vs =lbu=)

A 32-bit register holds 4 bytes, so loading a single byte (=0xFF=) requires deciding how to fill the upper 24 bits:

- =lb= *sign-extends* the top bit (=0xFF= becomes =0xFFFFFFFF=, which is =-1=).
- =lbu= *zero-extends* (=0xFF= becomes =0x000000FF=, which is =255=).

After running the block, inspect the =.data= hex view to see the four =FF= bytes written by =sw=.

#+NAME: bytes
#+BEGIN_SRC riscv
        .text
        li      t0, -1         # 0xFFFFFFFF
        la      t1, buf        # t1 -> scratch word in .data
        sw      t0, 0(t1)      # store the word: FF FF FF FF
        lb      a0, 0(t1)      # sign-extend byte FF -> -1
        li      a7, 1          # print int
        ecall
        li      a0, 32         # ' '
        li      a7, 11         # print char
        ecall
        lbu     a0, 0(t1)      # zero-extend byte FF -> 255
        li      a7, 1
        ecall
        li      a0, 10         # newline
        li      a7, 11
        ecall
        li      a0, 0
        li      a7, 10         # exit
        ecall

        .data
buf:
        .word 0
#+END_SRC

#+RESULTS:
: -1 255
