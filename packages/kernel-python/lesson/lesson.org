#+TITLE: Python in the Browser
#+SUBTITLE: Real CPython 3.14 running locally via Pyodide WebAssembly

Every code block on this page runs on *real CPython* compiled to WebAssembly (Pyodide, ~13 MB fetched once on first run and cached locally). Nothing is sent to a server.

A few quick things to know about how blocks behave:

- *Fresh namespace per block:* Variables and functions defined in one block are not shared with other blocks, and clicking *Run* resets the namespace from scratch.
- *Run to completion:* There is no single-stepping here. Output appears under the block and in the right-hand panel's console.
- *Live globals panel:* After a run finishes, the *Variables* panel lists every global created by your block along with its =repr()= and type. Syntax errors and uncaught exceptions show CPython's exact line number and traceback.

* Hello and operator precedence

=print= separates multiple arguments with a space by default, and standard CPython operator precedence evaluates multiplication before addition (=2 + 3 * 4 = 14=).

#+NAME: hello
#+BEGIN_SRC python
print("Hello, Python!")
print("2 + 3 * 4 =", 2 + 3 * 4)
#+END_SRC

#+RESULTS:
: Hello, Python!
: 2 + 3 * 4 = 14

* Loops and block globals

This loop builds a list of squares from 1 to 5. After running it, check the *Variables* panel: you will see both =squares= (=list=) and =n= (=int=, value =5=), because Python's =for= loop variable stays bound in the enclosing scope after the loop finishes.

#+NAME: squares
#+BEGIN_SRC python
squares = []
for n in range(1, 6):
    squares.append(n * n)
print("squares:", squares)
#+END_SRC

#+RESULTS:
: squares: [1, 4, 9, 16, 25]

* Functions: iterative Fibonacci

=fib= computes the nth Fibonacci number in O(n) time and O(1) space using tuple unpacking (=a, b = b, a + b=). In the *Variables* panel, =fib= shows up as a =function= object living in the block's global dictionary.

#+NAME: fib
#+BEGIN_SRC python
def fib(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a

print("fib(10) =", fib(10))
#+END_SRC

#+RESULTS:
: fib(10) = 55

Try breaking it on purpose: remove the closing parenthesis on =print= to see a line-mapped =SyntaxError=, or add =1 / 0= to inspect a full CPython traceback in the console panel.
